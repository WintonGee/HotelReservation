# Hotel Reservation System (Mock)

This is a mock full-stack hotel reservation system developed as a project, designed to manage hotel bookings, optimize query performance, and provide personalized reservation options.

## Features
- **Booking Management**: Manage hotel reservations and check availability in real-time.
- **Personalized Options**: Tailors reservation options based on room type, dates, and availability.
- **CI/CD Integration**: Automated pipeline for continuous deployment.

## Technologies Used
- Java
- Spring Boot
- React
- MongoDB
- Hibernate
- REST APIs
- CI/CD Pipelines

## Disclaimer
This system is a mock and was not used by Mission Inn or any other actual hotel. It was developed solely for educational purposes.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/HotelReservationSystem.git
    ```
2. Navigate to the project directory:
    ```bash
    cd HotelReservationSystem
    ```
3. Build and run the project:
    ```bash
    mvn clean install
    java -jar target/HotelReservationSystem.jar
    ```
